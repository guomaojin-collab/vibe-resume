# 模板目录

VibeResume 将可直接编辑的简历模板按投递场景分类。所有模板内容均为 mock 演示数据，替换为真实内容后再使用官方导出脚本生成 PDF。科研申请模板中的东南大学（SEU）校徽仅为示例，使用者应自行上传并替换为自己的学校校徽，或删除校徽。

## 实习就业

- [标准单页](./internship-employment/standard-one-page/README.md)：适合经历较少、强调快速扫描的默认投递版本。
- [高密度技术双页](./internship-employment/dense-two-page/README.md)：适合项目、实习或开源经历较多的技术候选人。

## 科研申请

- [Research Classic](./research-application/research-classic/README.md)：适合博士申请、科研实习、研究助理，以及需要突出论文和代表性研究成果的候选人。
