# Standard One-Page · 实习就业标准单页模板

![标准单页模板预览](./preview.png)

适合经历较少、强调快速扫描的实习和就业投递。内容按教育、实习、项目和技能组织，默认导出为单页长 PDF。

所有人名、学校、公司、项目、指标和联系方式均为 mock 演示内容，使用前必须替换为真实信息。

## 使用

在仓库根目录运行：

```bash
npm install
npm run export:pdf:internship-standard
```

输出文件：

```text
export/vibe-resume-demo.pdf
```

根目录的 `index.html`、`styles.css` 和 `npm run export:pdf` 保留为兼容入口，导出相同的标准单页示例。
